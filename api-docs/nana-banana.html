Nana Banana 2 / Nana Banana Pro · 图片异步 API 接入文档

入口路径使用 /v1/videos，最终结果为图片。

提交任务

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nana-banana-2",
    "prompt": "a cute banana mascot wearing sunglasses, studio lighting",
    "aspect_ratio": "1:1",
    "resolution": "1k",
    "images": ["https://your-cdn.com/ref.jpg"]
  }'

请求字段

字段说明
modelnana-banana-2 或 nana-banana-pro
prompt生成提示词
images多参考图 URL 数组，最多 7 张
aspect_ratio支持 16:9 / 9:16 / 3:4 / 4:3 / 1:1
resolution1k / 2k

查询任务

curl https://xxx.xxx.xxx/v1/videos/8c7e4b0e6f3b4b0a9e0a0d8f4f0c1234 \
  -H "Authorization: Bearer api-key"

返回字段

字段说明
id / task_id任务 ID，用于继续查询
status / state / task_status任务状态，三者值一致，便于兼容不同中转站
progress进度，0-100
image_url图片任务完成后的主结果地址
url完成后的通用结果地址，图片任务等同于 image_url
metadata.result_urls结果地址数组，通常取第一项即可
successstatus 为 completed 时为 true
finalcompleted 或 failed 时为 true
error.message失败原因，仅失败时返回

状态说明

status含义处理方式
queued排队中继续轮询
in_progress生成中继续轮询
completed已完成读取 image_url、url 或 metadata.result_urls
failed失败查看 error.message
